 🚀 Clipper Time AG – Back-End

Bem-vindo ao repositório oficial do back-end do Clipper Time AG!  

 ✨ Funcionalidade Principal
 
Este projeto realiza o cadastro de novos usuários ao site e envia um e-mail de confirmação.  
Após o cadastro:

1. 📬 Um e-mail de confirmação de cadastro é enviado para o usuário. 
2. ✅ Após essa validação, o acesso ao sistema é liberado.

Isso garante mais segurança e evita cadastros falsos ou mal-intencionados. 🛡️

 ⚙️ Funcionalidades Atuais

- 👤 Cadastro de usuários
- 📩 Envio automático de e-mail de confirmação
